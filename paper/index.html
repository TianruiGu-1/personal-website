Password Guessing Based on Deep Learning

Tianrui Gu · Yuan Pei Young Scholars Program, Peking University · Jun–Aug 2024
Advisor: Prof. Lianghuan Kang, Peking University

Download academic edition (PDF)

Abstract

Password guessing is a core tool for evaluating password strength and identifying weak credentials. This paper studies a GAN-based password-guessing approach built on WGAN-GP and a modified PassGAN architecture. It compares hit rates against the original PassGAN baseline on the RockYou dataset, analyzes how password length and letter–digit composition affect guessing success, and identifies early stopping as a practical training strategy. The paper concludes with user-facing recommendations for stronger passwords, including longer passwords, mixed character classes, avoiding reuse, and two-factor authentication.

Methods

The model extends PassGAN with an additional generator linear block and batch normalization before each ReLU in the residual blocks. Training and evaluation were run in Google Colab; performance was measured by hit rate on held-out password sets.
